# HCU 008 — diseño de producto

Sistema de emergencia en español para administradores y doctores. Conservar la identidad verde existente. Priorizar paciente, atención y acción disponible.

## Tokens
Fuente de verdad: `src/styles.css`. Verde clínico `#176b50`, verde profundo `#103f32`, fondo `#f3f6f5`, superficie `#ffffff`, texto `#203a32`, texto secundario `#657870`, borde `#dce5e0` y azul `#2563eb` exclusivamente para el foco. Segoe UI y Arial forman la pila tipográfica local; no descargar fuentes al compilar.

## Composición y accesibilidad
Sidebar persistente en escritorio; navegación desplegable de dos columnas en móvil. El tablero usa una mesa de trabajo clínica: métricas sobrias, búsqueda, filtros y una sola tabla para atención activa e historial. Desplazamiento natural del contenido, foco global visible, movimiento reducido y controles nativos con nombres accesibles. Formularios ocultos de acceso inertes.

Evaluación médica usa el “atlas clínico” como firma visual: una figura anatómica muscular frontal con marcadores verdes y naranja reservado para la zona activa. El título descansa sobre fondo blanco y las secciones recuperan el borde neutro del sistema para mantener una lectura tranquila.
